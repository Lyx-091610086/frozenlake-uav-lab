How should these results be read?
The original runner selects the best recorded checkpoint evaluation or final evaluation for learning algorithms. Planning methods use final evaluation. Evaluation episode counts differ across algorithms, so these are exploratory historical summaries, not a controlled final leaderboard. The supplied planning implementations also contain transition-model issues. Browser policies above use a separate terminal-aware solver. Of 24 defined maps, 23 have archived results; Prioritized Sweeping appears only in bytecode, not in the runnable source.
